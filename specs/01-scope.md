# 01. スコープ・用語集・ユーザストーリー

## 1.1 In Scope（v1で実装する）

- Mac上のtmuxセッションをサーバ経由でPWAから操作
- 単一ユーザ（本人）・単一マシン（メインMac）が前提
- Tailscale経由での外出先アクセス
- 承認プロンプト検知 → ネイティブボタン化
- マルチウィンドウ状態色分け
- PIN認証

## 1.2 Out of Scope（v1ではやらない）

- 複数ユーザ・チーム機能
- クラウドホスティング（自宅Mac固定）
- iOSネイティブアプリ
- Linux/Windows対応
- 音声入力
- 複数Mac切替
- セッション履歴の永続化（再起動で消えてOK）
- pty出力の完全レンダリング（ANSI色等は最低限でよい）

## 1.3 用語集

| 用語 | 定義 |
|------|-----|
| **セッション** | tmuxの1セッション。ユーザにとっての「作業空間」全体 |
| **ウィンドウ** | tmux windowを1つの「タブ」として扱う単位。1ウィンドウ=1 Claude Codeインスタンス |
| **ペイン** | tmux pane。v1では1ウィンドウ1ペインに固定（ペイン分割は扱わない） |
| **承認プロンプト** | Claude Codeがツール実行前に出す確認入力（[y/n]、番号選択等） |
| **承認待ち** | Claude Codeが承認入力を待っている状態（Window State = `awaiting_approval`） |
| **PWAクライアント** | ホーム画面追加されたWebアプリ。スマホ側のフロントエンド |
| **サーバ** | Mac上で常駐するNode.jsプロセス。SSE/HTTPを提供 |
| **Tailnet** | Tailscaleの仮想LAN。Mac・スマホがメンバー |

## 1.4 ユーザストーリー

各ストーリーには受入基準（Acceptance Criteria, AC）を併記。

### US-01: 出力を見る
> ソファでスマホを開くと、Macで動いているClaude Codeの最新出力が見える

**AC**:
- 接続から3秒以内に既存ウィンドウ一覧と最新出力が表示される
- 新たな出力が発生したら1秒以内に画面に追加される（自宅WiFi基準）
- 過去ログは少なくとも直近2000行までスクロールで遡れる

### US-02: 入力を送る
> 出力欄を見ながら、入力欄に質問を打って送ると、Claude Codeに届く

**AC**:
- Enterで送信、Shift+Enterで改行
- 送信完了は0.5秒以内に視覚的フィードバックが返る（送信ボタンが一瞬グレーになる等）
- 送信したテキストはローカルログにも追記表示される

### US-03: ツール実行を承認する
> Claude Codeが承認待ちになると、スマホ画面に承認バナーが出て、タップだけで判定できる

**AC**:
- 承認プロンプトが検知されてから2秒以内にバナー表示
- バナーには `許可` / `拒否` / `常に許可` の3ボタンが必ず出る
- ボタンタップで対応キーストロークが送信され、バナーが消える
- バナー表示中は誤入力防止のため通常の入力欄をdisabledにする

### US-04: 承認待ちに気づく
> ブラウザを閉じていても、承認待ちが発生したら通知が来て即座に開ける

**AC**:
- PWAインストール時のみWeb Push通知が飛ぶ（iOS 16.4+ / Android）
- 通知タップで該当ウィンドウが開いた状態でPWAが立ち上がる
- 通知到達は承認検知から5秒以内（ベストエフォート）

### US-05: ウィンドウを切り替える
> 複数のClaude Codeを並行で動かしているとき、どれが承認待ちか一目でわかる

**AC**:
- 画面上部にウィンドウタブが横並び
- 各タブのドット色: 緑=待機 / 黄=実行中 / 赤=承認待ち
- タップで該当ウィンドウのログ表示に切り替わる
- 切り替えは0.3秒以内

### US-06: 安全に外から接続する
> カフェからスマホで接続しても、自分以外には到達不可能である

**AC**:
- Tailnet外の任意の通信経路からはサーバに到達できない（疎通不可）
- Tailnet内であってもPIN入力なしでは画面表示されない
- PIN失敗5回でTailscale ACL以外の追加ロックがかかる（10分）

### US-07: 起動が簡単
> Macで作業を始めるとき、コマンド1発でサーバが立ち上がる

**AC**:
- 単一コマンドで起動（例: `npm start` 相当）
- 起動後、URLとPINがターミナルに表示される
- Ctrl+Cでクリーンに停止する（tmuxセッションは残る）
